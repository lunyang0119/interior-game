# 플레이어용 글 (copy)

게임 화면에 나오는 한국어 문장의 현재 관행이다. 기본 규칙은 `CLAUDE.md`: 플레이어 문자열은 한국어 해요체, 코드와 식별자는 영어.
이 문서는 코드에서 읽어낸 것이며, 어긴 곳은 맨 아래 "알려진 부채"에 적었다.

## 어디에 글이 있나

| 종류 | 위치 |
|---|---|
| 토스트 | 클라이언트 곳곳의 `toast("...")` (`client/src/bus.ts:73`) |
| 서버 에러 코드 -> 문장 | `client/src/api.ts:9` `MESSAGES` + `msgFor(code)`. 서버는 코드만 보내고 문장은 클라이언트가 가진다 |
| 열차 추적 | `client/src/train/strings.ts` (`S`, `MESSAGES`, `DEVICE_KO` 등) + `train/report.ts` (판 리포트) |
| 활동 기록 문장 | `client/src/ui/log.ts:59` `describe()` (이벤트 종류별 한 문장) |
| 정적 라벨/툴팁 | `client/index.html` (`title=` 속성, 버튼, 플레이스홀더) |
| 손님 쪽지/대사 | 서버 `guests.py` `NOTES_*` (comfort 구간별), 클라이언트 `npc/GuestNpcs.ts` `LINES`, `npc/Cat.ts` `MEOWS` |
| 복구 단계/체크리스트 이름 | `data/rooms/<id>.json` (`name`, `label`) |

새 에러 코드를 서버에 추가하면 `api.ts MESSAGES`에도 문장을 넣는다. 없으면 코드 문자열이 그대로 토스트에 뜬다 (`msgFor`의 폴백).
열차 페이지는 별도 `MESSAGES`를 쓴다 (`train/strings.ts:20`).

## 말투

- 해요체 종결: `~어요/~아요/~예요/~이에요/~네요/~까요?`. 합쇼체(`~습니다`)는 쓰지 않는다. 명령/부탁은 `~해요`, `~해주세요`, `~주세요`.
- 대상을 높이지 않는 담백한 안내체다. 주어는 보통 생략하고, 사람 이름이 필요할 때만 `${who}가 ...했어요`.
- 문장 끝은 마침표를 쓰지 않는 게 지배적이다 (토스트 대부분, `api.ts`의 `MESSAGES` 대부분). 한 토스트에 문장이 둘이면 첫 문장 뒤에만 마침표가 붙는다.
- 이모지는 라벨 앞머리에 하나 (`🎣 낚시`, `📜 기록`, `💰`은 금액 뒤). 문장 중간 장식은 거의 없다.
- 조사: 받침이 가변인 변수 뒤는 `을(를)`, `이(가)`, `은(는)`을 그대로 쓴다 (`log.ts:63`, `board.ts:79`, `main.ts:220`). 이름에 한해 `가`로 고정한 곳도 많다 (`${m.player}가`). 새 코드도 이 둘 중 하나를 따르고, 조사 선택 함수를 새로 만들지 않는다 (열차만 `particle` 변수로 가른다, `train/main.ts:241`).

## 길이와 형태

- 토스트: 한 문장, 10-25자가 대부분. 최대 두 문장(약 60자, 계정 로그인 만료 안내). 길수록 표시 시간이 늘어난다 (`1500 + 글자수*60`ms).
  - 결과 알림: `쪽지를 남겼어요`, `아바타를 저장했어요`, `납품했어요 (3/5)`, `팔았어요 (+30💰)`, `치웠어요 (환불됨)`
  - 시작/상태: `${floor}층으로 내려가요`, `${acct.id} 계정으로 들어왔어요`, `바깥은 아직 준비 중이에요`
  - 다른 사람의 행동: `${m.player}가 고양이를 쓰다듬었어요`, `${by}가 ${name}을(를) 캤어요 (+${v}💰)`
- 수량/보조 정보는 괄호: `(+30{coin})`, `(3/5)`, `(환불됨)`. 구분은 가운뎃점 ` · ` (`오늘 밤 손님 3명 · 숙박료 48{coin} 예상 · 객실 3곳`, `board.ts:46`).
- 금액: 숫자 + `{coin}` 토큰을 붙여 쓴다 (`48{coin}`, `+30{coin}`; 화면에서는 금화 아이콘, [icons.md](icons.md)). 공동 자금도 같다. `confirm()` 문구는 숫자만.
- 버튼/탭 라벨: 명사 또는 짧은 동사형 2-6자 (`상점`, `놓기`, `취소`, `남기기`, `들어가기`, `납품하기`, `바닥·러그`). 이모지는 하단 큰 버튼과 칩 앞에만.
- 툴팁(`title=`): 설명 한 구절, 마침표 없음 (`지금 있는 방 · 남은 부서진 물건 · 복구 단계 (누르면 자세히)`).
- 빈 상태: `아직 아무 일도 없었어요`, `검색 결과가 없어요`, `아직 아무것도 안 적혀 있어요`. `아직 ...`으로 시작하는 것이 관행이다.

## 에러 문장

- 형태: 무엇이 안 되는지를 사실로 말하고, 바로 할 수 있는 다음 행동이 있으면 덧붙인다. 사과나 "오류"라는 말은 쓰지 않는다.
  - 상태: `돈이 부족해요`, `이미 무언가 있어요`, `아직 들어갈 수 없는 곳이에요`, `없는 방이에요`
  - 상태 + 행동: `위에 올린 걸 먼저 치운 다음 다시 시도해주세요`, `닉네임이 겹쳐요. 다른 걸로 써주세요`, `요청이 너무 잦아요. 잠시 후 다시 시도해주세요`
  - 지시: `먼저 계정을 골라주세요`, `광석 옆으로 가야 해요`, `낚싯대를 먼저 던져요`
- `없는 X예요`(존재하지 않음), `이미 ...`(중복/만료), `아직 ...`(조건 미충족) 세 어휘가 반복된다. 같은 상황이면 같은 어휘를 쓴다.
- 코드 자체를 보이는 폴백은 `String(e)` 하나뿐이다 (`toast(e instanceof ApiError ? msgFor(e.code) : String(e))`).
- 규칙 위반 힌트는 구체적 물건/위치를 넣는다: `테이블 등의 위에만 놓을 수 있어요`, `한 가구 위에만 놓을 수 있어요`.
- 잠긴 곳: `아직 들어갈 수 없어요 — ${장소} '${단계}' 단계를 끝내면 열려요` (이유 + 해결 조건, `main.ts:38`).
- 열차 추적은 같은 해요체지만 조금 더 건조하다: `정원이 가득 찼어요`, `관제만 할 수 있어요`. 리포트 본문(`train/report.ts`)은 `~했다` 평서체(`놓쳤다`, `빠져나갔다`)에 em dash가 섞인 로그 톤이다 (게임 연출용이라 별도 취급).

## 숫자와 날짜

- 층: `3층`. 칸: `2칸`, 크기: `2×3` (곱셈 기호 `×`). 날짜 `10/16 14:05` (`note.ts fmtWhen`). 상대 날짜 `어제`, `3일 전`, `2일 뒤`, `오늘 밤`.
- 사람 수 `3명`, 번째 `137번째`, 횟수 `3번`.

## 피할 것

- 문장 속 em dash(`—`). 구분은 ` · `, 쉼표, 마침표로.
- `A가 아니라 B예요` 식의 대조 문형. 해야 할 것을 바로 말한다 (`바닥이 아니라 벽에 걸어요` -> `벽에 걸어요`).
- 느낌표 연타(`!!`, `?!`). 느낌표는 보상/성취 순간에 한 개까지만.
- 이모지를 장식으로 문장 곳곳에 뿌리기. 라벨 앞 하나, 금액 뒤 `💰`, 종류 표시(🐶 개 손님, 🐱 고양이)만.
- 합쇼체, 반말, 영어 약어(`ok`), 게임 밖 이야기(`시트`, `토큰`)를 새로 들이기. 이미 있는 곳은 아래 부채.
- 서버가 보내는 에러에 문장을 넣기. 코드(영문 snake_case)만 보내고 문장은 `api.ts MESSAGES`에 둔다.

## 알려진 부채 (현 코드가 위 규칙을 어기는 곳)

- em dash `—`가 플레이어 문장에 많다. 토스트: `main.ts:38`, `MapScene.ts:446` (`아직 들어갈 수 없어요 — ...`), `train/main.ts:350`, `:381`. 기록/게시판: `log.ts:77`, `:78`, `:177`, `board.ts:70`, `:78`. 열차 리포트 전반 (`train/report.ts:25-96`, `train/ui/report.ts:15`).
- 합쇼체: `tools/preprocess/README.md`는 맵 문 안내를 "들어가시겠습니까?"로 적지만 코드(`bus.ts` 주석, `map:enter-ask`)는 `<name>에 들어가시겠어요?`다. 코드 쪽이 기준이다.
- 말투가 어긋난 에러: `sheet_unavailable` (`시트에 연결이 안되었어요. 오류니 잠시 뒤, 다시 한 번 들어와주세요.`, 마침표, 쉼표 위치 어색), `out_of_bounds` (`마크로 치자면 파랜드에요. ...` 밈, 마침표), `main.ts:62` (마침표로 끝나는 두 문장). 나머지 `MESSAGES`는 마침표가 없다.
- `ok`(영어)가 `index.html:72` 플레이스홀더에 있다. 내부 용어 `시트`, `토큰`, `ID`가 계정 흐름 문구에 그대로 나온다 (`not_in_sheet`, `토큰 재발급 완료`, `시트에 새 행 추가됨`).
- 마침표가 붙은 토스트: `복구 링크 복사됨.` (`accounts.ts:37`). 체언 종결(`복구 링크 복사됨`, `토큰 재발급 완료`, `시트 동기화 완료`)이 해요체 `~했어요`와 섞여 있다. 지배적인 쪽은 `~했어요`다.
- 느낌표: `!!` 연타는 없지만 한 문장에 둘이 있는 곳이 있다 (`DockScene.ts:296` `입질이 왔어요! 지금 낚아올려요!`).
- 에러 폴백 `main.ts:228`: `시작 실패. 게오에게 멘션주세요: ...` (제작자 이름이 들어간 특수 문구, 따라 하지 않는다).
- "~이(가) 열렸어요" 같은 임시 조사 표기가 화면에 그대로 보인다. 조사 선택 로직을 만들기 전까지는 기존 표기를 쓴다.
